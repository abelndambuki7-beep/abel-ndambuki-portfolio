# Abel Ndambuki Portfolio — Vercel-ready starter

## Deploy
1. Create a GitHub repository named `abel-ndambuki-portfolio`.
2. Upload the contents of this folder to the repository root (not the folder itself).
3. In Vercel, choose **Add New → Project**, import this GitHub repository, and click **Deploy**. No build command is required; the site is static HTML.


## Important limitation
The Admin panel in this prototype uses browser-local storage. It is not a secure cloud CMS, and changes are not synced between devices or published for other visitors. Do not use it for private admin credentials or sensitive inquiries. The secure cloud admin, shared media storage, server-side email notifications, and analytics still need implementation.
